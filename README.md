# Web Map - Voies structurantes du Grand Abidjan

Projet de web mapping informatif des voies structurantes à aménager dans le Grand Abidjan, dans le cadre du PTUA Phase 2.

## Contenu

- `index.html` : page d'accueil et carte interactive.
- `pfe-custom.css` : styles personnalisés de la page d'accueil, de la carte et de la légende.
- `pfe-custom.js` : logique personnalisée pour la légende des 6 voies structurantes.
- `images/` : logos et image d'accueil.
- `layers/`, `styles/`, `resources/`, `webfonts/` : fichiers générés par qgis2web.

## Hébergement avec GitHub Pages

Déposer directement tout le contenu de ce dossier à la racine d'un dépôt GitHub public, puis activer :

`Settings > Pages > Deploy from a branch > main > / root`

Le site sera disponible à une adresse du type :

`https://votre-utilisateur.github.io/nom-du-depot/`

## Remarque

Le fond OpenStreetMap nécessite une connexion Internet.
